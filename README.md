# NeXT Stage — Portfólio

Transformamos ideias em software de alto nível.

Portfólio do time NeXT Stage: três desenvolvedores fullstack especializados em aplicações web, mobile e APIs.

## Stack

- **Framework:** Next.js 16.2.9 (App Router, Turbopack)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4
- **Animações:** Framer Motion
- **Ícones:** Lucide React + Tabler Icons
- **Tipografia:** Geist + Instrument Serif

## Seções

- **Hero** — título gradiente, stats, CTA
- **Serviços** — 5 cards em bento grid
- **Tech Stack** — 6 categorias de tecnologias
- **Equipe** — 3 devs com bio e links
- **Portfólio** — 3 projetos com mockup
- **Contato** — formulário + informações

## Começando

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build    # produção
npm run start    # servidor produção
npm run lint     # ESLint
```
